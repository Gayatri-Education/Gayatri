# Gayatri V4 Role-Based Access Control (RBAC) Policy

## 1. Core Personas & Portals
The V4 architecture establishes four strict portal boundaries, each tied to a corresponding user role within the `UserRole` enumeration (`central_platform.models.schema`).

### 1.1 `student` -> Student Portal
- **Scope:** Bounded to their own `StudentProfile` and associated `LearningEvent` records.
- **Permissions:**
  - `READ` own progress, mastery, and recommended roadmap.
  - `WRITE` (append-only) interaction logs via the AI tutor session.
  - Cannot access other students' records or any configuration data.

### 1.2 `teacher` -> Teacher Portal
- **Scope:** Bounded to the `Course` / class groups they are assigned to.
- **Permissions:**
  - `READ` aggregate analytics, specific student profiles, and misconceptions within their assigned classes.
  - `WRITE` teacher instructions (e.g., focus areas) for the AI to follow.
  - `WRITE` resolution flags for alerts generated by the system.
  - Cannot access student data outside their assigned organization/course.

### 1.3 `parent` -> Parent Portal
- **Scope:** Strictly bounded to their explicitly linked child accounts.
- **Permissions:**
  - `READ` high-level progress reports, recent activity streams, and time-on-task metrics.
  - Cannot modify learning state or view other students.

### 1.4 `org_admin` & `super_admin` -> Admin Portal
- **Scope (ORG_ADMIN):** Bounded strictly to their specific `Organization` ID.
- **Scope (SUPER_ADMIN):** Global cross-tenant access.
- **Permissions:**
  - `READ/WRITE` users (onboard teachers/students).
  - `READ/WRITE` organizational configurations, billing, and global metrics.
  - `ORG_ADMIN` cannot see any data or users belonging to a different tenant organization.

## 2. Enforcement
All data access in `central_platform.db.PlatformDatabase` must require an explicit contextual injection of the caller's role and organization ID to prevent IDOR (Insecure Direct Object Reference).

Tenant isolation is currently verified via `tests/test_phase07_tenant_isolation.py`.
